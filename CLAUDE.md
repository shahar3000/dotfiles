# Commit rules

- Each commit is a standalone logical change — don't bundle unrelated fixes
  or cleanups into one commit.
- The commit message body explains what was done (and why, when the reason
  isn't obvious from the diff itself).
- Wrap every commit message line (subject and body) at 80 columns.
- No `Co-Authored-By` / co-author footer.
- Sign off every commit (`git commit -s`).
